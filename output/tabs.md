# Theory in E: tabs

How to read these tabs: the top line is the thinnest string (high e) and the bottom line is the thickest (low E). A number is the fret to press, and 0 is an open string. In a chord, a string with only a dash is not played. Chord tabs show one chord per column, in order; strum each for the number of beats in the post. Scale tabs go up one octave and back down. Arpeggio tabs go up two octaves and back down, one note per beat.
