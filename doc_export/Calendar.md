# Calendar

The series runs weekly on Mondays for 36 weeks, from 16 November 2026 to 19 July 2027. Audio for each post is due the Thursday before it goes out. The Monday start is an assumption, so shift every date by the same amount if you prefer another day.

Two dates fall over Christmas: F6 on 21 December and R1 on 28 December. Skipping a week there pushes every later date back by seven days. Every post's text is already drafted, so each starts at "Draft written"; update the Status column as each post moves on.
